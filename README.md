# AI & Automation Portfolio

Portfolio website for Manu Gupta, showcasing AI tools, business automation, custom business apps, Power BI dashboards and websites built for clients in India and the UK.

**Live site:** https://manu-gupta-ai-automation.netlify.app

## What's on the site

- Services: automation (n8n, Make.com), websites and landing pages, custom business apps, dashboards, AI tools and training
- A filterable portfolio of shipped projects
- Case studies and a contact form for project enquiries

## Tech

- Single-page static site: HTML, CSS and vanilla JavaScript, no build step
- Responsive layout with automatic light and dark themes
- Contact form powered by Netlify Forms, with email notifications
- Hosted on Netlify

## Run locally

Open `index.html` in a browser. The contact form only submits when the site is served by Netlify.
